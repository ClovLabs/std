    Interface ScalarConfiguration

    The Scalar API reference configuration options.

    Only the JSON-serializable ones: the configuration is inlined in the page with JSON.stringify, so functions (events, customFetch, plugins, slug generators, custom sorters) would be dropped. url is set by the plugin.
